# 飞行人员训练大纲阅读

## 报装

1. 场景：主人要求读训练大纲、解释课程、安排训练路径、核对课时或判断资格恢复还缺什么。
2. 能干：核对真实版本与机型，按人员和触发原因选课，读全课程、评估、失败处理、保持恢复、记录及后续办理条件。
3. 边界：本篇独立使用，直接读取必要的原始资料；不依赖其他技能、远端链接或看门狗程序。不能用经验编造未列的课程或替局方、公司批准减免。

## 综述

简短开场“主人，技能已加载。先分清人员和训练类别，再把进入条件、课程、检查和资格生效逐项对上。”对主人输出按仓库规约使用纯txt。

本篇侧重训练的完整实施链。《飞行技术管理手册》用于补足管理程序、权限、检查后果、聘任和资质发布，直接读它的相关原文即可。训练合格和运行资格生效分开结论。

## 一、先辨认任务和人员

1. 识别主人要的是单项解释、完整训练路径、人员缺项核对、恢复方案、版本对照还是全面学习。只读取本轮相关课程、通则及交叉条款；全面梳理才逐章列覆盖情况。
2. 先取公司、机型/构型、原机型及组类、原职务和等级、现岗位、人员来源、既有训练/资质、首聘/新聘/复聘、目标、判断日期。
3. 区分新雇员、初始、转机型、升级、差异、缩减课程、定期复训、重新获得资格、教员/检查员训练、专项运行训练。不把同型别外公司转入等同转机型，不把副驾驶晋升技术等级等同机长升级训练。
4. 恢复业务先取失去资格的原因、发生日期、最后有效训练/检查、基准月、近期运行、当前可行使权利、既往不合格次数及处理通报。多个原因并存就分别核查，不只挑训练最少的一条。
5. 个人完成情况必须用训练记录、检查单、证照、飞行经历、批准/聘任和系统资料证明。材料缺失标“待核”，不把“参加过”“排了课”“有代码”写成合格。

## 二、校准来源和读取方法

### 2.1 来源卡

登记本轮文件路径、名称、手册编号、版次/修订号、签批、修订记录、有效条款清单、页眉页脚、生效日期、公司/机型范围、读取限制。标题含“无修订记录”仍需打开正文核实。

编制参考为训练大纲R03-01 V6、技术管理手册R01-08 V1、资质管理逻辑.docx和看门狗菜鸟教程。不是以后默认的现行规则库。本轮没有手册时只可说明阅读方法，不能将本篇示例当当前办理依据。

样本训练大纲第1章写明适用于南货航B777训练，不可直接推广其他公司/机型；03-01修订表写2026年3月16日，页脚却仍为2026年1月10日，部分签批日期未填。分别报告这些证据，不能用文件名V6、文件修改时间或页脚单独认定已批准现行有效。

### 2.2 依据使用

1. 正式手册、其适用附录和明确适用的批准/临时修订文件提供业务依据；引用其他规章、运行规范、第三方课程时，要核对相应文本和批准范围。只见引用标题不等于已取得全文。
2. 菜鸟教程先用于辨认主线、例外、恢复分支和容易漏的数字，再用其来源索引回查手册。confirmed也须核原文；partial不补成完整规则，special不混入普通等级链。
3. 资质管理逻辑提供“入口→等级→教学/检查权利→资质保持”的理解框架。样本含未接受的修订，读取时区分当前显示、插入建议、删除文字，不擅自接受或合并修订。
4. 通则和专章、训练大纲和技术管理手册需要共同阅读。不同对象/阶段的差异分别保留；同一问题的矛盾并列原文、版本、适用性和待解释点，不能默认选较新、较严或较省的一条。

### 2.3 完整提取而非关键词摘抄

1. 先读目录、编号编制、正文层级。Word自动编号需核对编号定义/目录与实际正文，纯文本没显示款号不代表没有，不能自行编款号。

3. 核查附录、课程表、图片、脚注/尾注、页眉页脚、文本框和修订。若有扫描/OCR，数值、比较词、否定词及跨页表必须回看原页。图像、表格字体被提取丢失时注明局限并局部查看，不据空文本判定留空。
4. 搜索名称、缩写、近义词及“进入条件/资格保持/过期/不合格/补考/记录”等定位后，读完专章及其引用的通则、管理条款。命中一处不等于规则完整。
5. 区分有内容、明确有意留空、该分节不适用、未取得被引用文件、提取失败、尚未阅读。只有原文明示“有意留空”且确认所在位置，才记为留空；“未规定”不等于无限期有效或免训。
6. 引用用文件版本、章节/款及标题、短原文；可靠印刷页码才当手册页码。提取块号、行号和PDF页序另行标识。不要为Word动态分页臆造页码。
7. 只做有必要的小范围工具读取。脚本仅辅助，先落盘再跑；不默认增加测试框架、全书图片渲染、批量浏览器或后台服务。

## 三、逐章使用同一张课程卡

即使专章顺序不同，也要核全以下字段；没有内容分别写“不适用/未规定/待补”，不要填零。

1. 课程标识：全名、训练类别、机型/构型、岗位、适用人群、目的和完成后的目标能力。
2. 进入条件：证照、签注、语言、体检有效范围、原资格、经历、选拔/推荐、先修课程；明确条件是并列、任选还是不同人群分支。
3. 教学条件：资料、训练机构及授权、设备批准/等级/构型/视景、教学方法、教员和检查员资格、在座位置、编组及替代限制。
4. 课程安排：地面理论、训练器、固定/全动模拟机、本场模拟机/飞机、本场训练、航线经历、检查；逐阶段记课次、小时/课时、每人/每组、是否含考试、课前准备和讲评是否另计。
5. 科目明细：必训动作、条件、飞行次数/航段/起落、PF/PM、左右座、昼夜、人工飞行高度/方式、着陆/复飞、每课要求与周期覆盖要求。
6. 质量和评估：能力标准、合格线、关键项/评分逻辑、考试形式、推荐、考试员、记录单、合格后去向。
7. 失败处理：首次不合格、每次补训/补考、时限、最多次数、审批、追加经历、退出/降级/停飞以及重新申请条件，按发生次序展开。
8. 时限：起算事件、阶段衔接、周期、基准月和允许窗口、失效第一个月怎么算、恢复后保留还是重建锚点。
9. 资格保持与恢复：课程更新、经历/复训/检查要求、超期分档、依赖资格失效、能否结合其他训练、批准的替代/豁免及其范围。
10. 记录及生效：学习时间/内容/地点、成绩、签字、证书、云执照/电子记录、执照签注、审批发布、聘任、系统入库及保存期限，按该项实际要求闭合。

课表“覆盖了某知识”只证明课程内容；必须另查它是否满足独立资格获取、检查、签注和发布。结合训练不等于免除科目，减课时不等于取消考试。

## 五、训练主线的阅读顺序

以下数字是编制样本的核对锚点，使用时重新核对本轮原文、分支和适用性，不直接拿本篇代替课程标准。

### 5.1 新雇员与转入

1. 读第1章通则→第2章进入条件和课程→第2章合格后计划→技术管理第3章外公司转入。毕业生与其他公司/军转来源的140/40小时是不同人群分支，不加在一起，也不当作后续转机型140小时的同一课程。
2. 新雇员中危险品、安保、CRM、疲劳、应急等课程与独立专章比对，查可否结合、替代及是否仍需独立检查/记录。例如第2章一类新雇员安保列12小时，第44章安保初/复训为6学时，不能无依据把一处改成另一处。
3. 同型别转入不是自动再跑第5/7章：先分临时/非临时、是否转机型、是否获批缩减复训、原公司培训体系和已有B777资格。完成规定训练检查后恢复原有资质的前提、范围和基准月处理都要核。

### 5.2 副驾驶转机型及后续等级

1. 第5章进入条件要读语言、执照、体检与所有经历分支。“原136吨（含）以下组类II飞机、按121运行、副驾驶250小时”是其中一个限定入口，不是全体统一条件；不能只摘逻辑笔记标题的250小时。
2. 按理论→模拟机→本场模拟机→应急时序/航线经历→记录读全。140小时理论内是否包含训练设施教学、固定/全动模拟机课次、本场训练座位和动作分别记，不用模拟机总小时替代各科目。
3. 本场模拟机检查合格后进入A1；建立不少于25小时、至少4次飞行、至少3次操作驾驶员、一次10000英尺以下人工飞行，再查技术管理的一体化课程、综合考试、起落/人工飞行分钟和A2检查。相同阶段同一项25小时不累计两遍。
4. 大纲不能独自解释A2→B→C→D。直接补读技术管理第3章及附件的阶段课程、起落、英语通信、模拟机或豁免、专项检查、最近复训要求和航线检查PF/PM条件，再接审批发布。
5. 原机型C及以上恢复原技术标准、资深副驾驶右座通道、E类未完整规定分别处理，不用标准新学员路线覆盖全部人员。

### 5.3 机长转机型和任机长

1. 先读第7章进入条件：D类机长经历不少于1000小时、总驾驶员经历不少于4500小时等，与语言、执照、体检一起核；“原则上航线教员优先”不要改写必需项。
2. 地面140小时、模拟机、实践考试、本场左座训练、应急、右座经历、左座经历分别列出。样本右座不少于2航段；左座操作驾驶员不少于4航段25小时、夜航不少于2航段、一次10000英尺以下人工飞行。技术管理另有4次飞行/3次操作驾驶员和25小时/4起落，保留不同字段。
3. 理论完成到进入模拟机、本场训练在模拟机后完成、教员推荐到实践考试的60天分别标起算和完成/开始要求；超期补学或熟练飞行等措施按各条读，不套通用“过60天全重训”。
4. 接读技术管理第3、4、6、7章、附录H：大型转重型一检/二检与重型转重型仅一检、上限与重检、批准聘任、Z类过渡状态、B类运行与新机长天气限制、后续转C/D条件。实践考试合格不等于独立任机长。
5. 本场检查后的120天100小时独立监控；不是“25小时完成就闭合”，也不是从资质录入当天重算。

### 5.4 教员与检查员课程

1. 第9章：初始与原有教员经历入口、基础/机型理论、在座、本场模拟机、航线带飞能力检查、资格更新、年度带飞检查和过期处理。再读技术管理附录K的L1/L2条件、权利、年度考核和终止。
2. 第10章：基础/机型理论、在座、模拟机面板及教学、本场训练、实践考试、更新、失败和恢复。再读附录A的B1—B4选聘/使用/考核，不能靠课程完成自动授予公司教员分级。
3. 专职模拟机教员独立列首次申请的曾任/未曾任教员分支、批准函、年龄/体检/持照例外、评估、半年观察或LOFT、年度认可和续聘。与参加航线运行的型别教员条件分开。
4. 第12章：检查员进入、理论、模拟机和年度复训；接技术管理附录B核检查类别、任期、授权、监察、终止和重申间隔。完成教员训练不等于检查员合格。
5. 第9/10章教员资格过期、更新/年度检查失败、底层机长资格失效，各按原条款；涉及100小时机长经历、4小时理论、在座、面板、评估/实践考试时保留适用分支。技术管理另有身体原因恢复且原资格有效的规定，交界不清须列冲突，不能统一“自动恢复”或统一“从头初训”。

## 六、重获资格必须先分失效原因

### 6.1 选择路径
