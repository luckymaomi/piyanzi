# 资质录入检查预提示

## 报装

合集「能做什么」时只取本段；改能力只改本文件。

```
资质录入检查预提示
1. 场景：主人甩录入通知/名单，先拆成「每人要录什么、不要录什么、先核什么」（货航仅 777 机型）
2. 能干：解析通知 → 映射常用代码（报务/单飞区域/货航常见机场）→ 套录入铁律 → 输出预提示清单；疑点单列
3. 铁律：只预检；机型只认 777；表外代码不编；口语机场落 IATA+资格码；例外必须写进清单
4. 节奏：默认预检；要改正式系统由主人自己录或另下实写令
```

## 综述

简短开场：“主人，技能已加载。先拆通知中的人员、资格和例外，再核代码与录入注意事项。”默认只出预提示，不代点系统；货航机型范围为777，细码按配套字典查，疑点单列。

### 作战阶段

| 阶段 | 做什么 | 边界 |
| --- | --- | --- |
| **预检** | 解析通知、映射代码、套铁律、出录入检查预提示 | 不登录、不改飞行门户/天健 |
| **实写入** | 本 Skill 默认不做；若主人点名要改本地台账/Excel，核对已指定目标，缺项才问，先备份 | 不把「预提示」当成已录入 |

默认只出预提示，无需追问是否另写文件。主人另行要求本地回填时，只核对缺失的目标与范围；已明确的沿用。

## 录入铁律（来自业务备忘，预提示必套）

套预提示时优先套本节；与通知冲突时以通知例外句为准并写入清单。

1. **副驾驶录入前。** 核岗位表是否已有 F/O 或 S/O；核资质表 A1/A2。发布岗位：A1 → S/O，A2 → F/O。
2. **A1。** 成为 A1 类副驾驶 → 同步发 **777** 机型资格（通知写「不添加机型资格」则禁止同步，清单写死）。关键节点（排班/薪水相关）需复核：A1 类副驾驶、Z 类机长、B 类机长、A 类教员。
3. **型别教员。** CAPTB 同步 SIMT。
4. **改飞行学员。** 岗位 S/S；资质 S/T + 机型组 **777**。
5. **退回副驾驶。** 同步取消 ACAP。A/B 类机长含 ACAP；C/D 类机长需取消 ACAP。
6. **重航划转。** 基地 CAN、主基地 CSG；非 777 机型划入 → 学员路径（S/S、S/T、机型组 **777**）；实践考试通过后原机长→Z、原副驾驶→A1。
7. **机型范围。** 本岗录入预提示只覆盖 **777**；不扩展其他机型。
8. **人力关注变更（月统计口径，预提示可不展开操作）。** 副驾驶 FOA1/FOB/FOC/FOD，机长 CAPB，教员 CAPTA；Z 类转机型 1 年改装保护期。

---

## 铁律

0. **默认预检。** 产出是给人看的录入检查清单，不是系统已办结。
1. **不臆造代码。** 本文件「常用映射」没有的，打开 `资质代码` / `特殊机场资格代码` 查；仍无则标「未收录，请主人给码」。
2. **机型只认 777。** 本 Skill 服务货航运行，机型组 / 机型资格默认只有 **777**（B777）。通知写「同步机型资格」「机型组」而未点其他机型 → 一律按 777；若出现非 777 机型字样 → 停，标疑点问主人（默认不录入其他机型）。
3. **报务 ≠ 单飞。** 通讯报务用 E 开头；区域单飞用 R 开头（区域类）。主人口语说「美报/欧报」→ E*；说「北美单飞/欧洲区域」→ R*。不要混挂。
4. **机场落码。** 货航常见机场见下表；有排班/资格码的必须落到 Rxxx（如 RLAX）；表内无 R 码的写出中文+IATA，并标疑点问主人是否另有系统码。只写中文地名不出码（或不出 IATA）不算完成。
5. **例外优先。** 「面试不合格」「不添加机型」「仅恢复××」等否定句，必须在对应人名下写清「不录××」。
6. **一人一行。** 多人通知按人拆开；同一人多资质合并到该人一行；推荐区每人换行，禁止挤行。
7. **不确定先问。** 「北美责任机长」等业务专名若对应额外岗位/专码且表内无专名，先按通知字面拆区域+机场，并单列「是否还有专码/岗位动作」问主人。
8. **连查弹药。** 细查字段时读 `core/zizhi-daima.md`、`core/teshu-jichang-zige-daima.md`；副驾驶积分总表另走「副驾驶流转更新」。

## 通知解析步骤

收到主人通知后，按序做：

1. **切块。** 按句号/分隔符拆成独立事件（例：A1 一批；不合格例外；北美责任机长新增；某人恢复全部）。
2. **提人。** 每人姓名（有员工号更好）；多人用顿号、竖线、逗号分隔的，按人拆。
3. **提动作。** 新增 / 恢复 / 取消 / 不添加 / 延期 等。
4. **提资质对象。** 技术等级、报务、单飞区域、机场、机型、「恢复所有」等。
5. **映射代码。** 先查本文件常用表，再查两份代码 Skill。
6. **套铁律。** 先套「录入铁律」，再套本节上的例外句、A1↔机型、岗位、ACAP。
7. **出预提示。** 按下方骨架出原文+推荐+疑点（可增减，不死抠）。

### 竖线名单读法

形如：`甲某欧洲，北美、安克雷奇、洛杉矶丨乙某，北美、洛杉矶`

1. 以 `丨` 或 `|` 分人。
2. 人名后的「欧洲/北美」→ 同时考虑报务 E* 与单飞 R* 是否都要；**通知只写区域地名且场景是「责任机长/单飞」时，默认先挂区域 R* + 机场码；是否加报务 E* 写进疑点问主人**（除非通知明确「报务」或「通讯」）。
3. 机场名 → 机场资格码。

## 预提示输出模板（对主人，纯 txt）

禁 markdown（无井号、加粗、列表符、表格、代码反引号）。整段纯 txt。

推荐骨架（标题带冒号；可按通知长短增减）：

`
录入检查预提示（预检，未写入系统）

原文：
〔主人通知原文原样粘贴，不改字、不扩写〕

推荐：
姓名（工号）发中文（代码）…
姓名（工号）发中文（代码）…

疑点：
…
…
`

行式口吻（死规矩）：

`
甲某（100001）发A1副驾驶（FOA1）北美报务（EAMA）区域-美洲*（RAMA）
`

即：姓名（工号）+「发」+ 中文名（代码），多项直接连写；例外写进行内（如不添加机型资格）。

格式铁律：

1. 三段标题固定写「原文：」「推荐：」「疑点：」（带冒号）；无疑点可整段省略「疑点：」。
2. 原文与主人当次通知一字不差。
3. 推荐：每人独占一行换行隔开，禁止多人挤同一行；中文在前、代码括后。
4. 疑点：一行一条，不写 1. 2. 序号。
5. 员工号从花名册/台账取；取不到写姓名并疑点补员工号。
6. 责任机长/单飞且通知只写区域地名：推荐默认只出 R* + 机场码；E* 是否加放疑点。
7. 「恢复所有」无清单时：推荐行写「发恢复所有（清单待补）」；不臆造代码。
8. 花名册已有的码不进推荐行。
9. **Skill 正文样例禁止写真实姓名/真实员工号**；只用甲某、乙某等占位。对主人当次实办可用花名册真名真号，但不回写进本文件。

## 不做

1. 代登录飞行门户录入、发布、指派检查。
2. 把预提示写成「已录入完成」。
3. 编造未收录代码或机场码。
4. 培训排班、签到、皇帝截止（留给培训类 Skill）。
5. 运行资格导出/筛选等截图死流程。
