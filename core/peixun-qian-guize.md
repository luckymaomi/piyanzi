```

1. 场景：排课、盯课时对照谁动谁不动、提前多久、CRM 未完成怎么数

3. 铁律：有效期算法见「飞行部培训规则速查」；不飞与领导名册见「飞行部人员天梯榜」；CRM 统计跟培训皇帝 CRM 年度核对
4. 节奏：默认只讲清；算有效期去规则速查；粗点其他训人头去培训完成粗统计
```

### 4. 领导——培训侧怎么动手

名册与（1）→（6）层级序、特征备注见 **飞行部人员天梯榜**「组织层级天梯」。

照常按到期排。四条：

1. **单独通知**：本轮名单出现名册中任何人，提示主人「名单含领导，请单独通知领导」。  
2. **多留裕度、多留集中改期空间**：有领导的场次不要卡在「刚好提前一个月」；再往前一点、班次前后多留空档。领导改期常带动同场其他人。  
3. **领导临近到期要更早排**：普通人约提前两个月；领导宜提前两个月以上，尽早落进计划。  
4. **培训表名单排在最前，按层级序**：同一期 / 同一项目 sheet 里领导排在名单最前；多名领导按（1）→（6）序，同档内按表内先后（照顾面子，不夹在普通学员中间或甩到后面）。

## 二、实操提前量

死规则里的窗口多宽、有没有窗口 → 规则速查。本页只写**怎么排课留余量**。

### 1. 总口径（主人确认）

航班延误、锁班变动、临时抽人，课经常排了去不成。  
所以**不要卡死在到期当月、更不要卡死在到期日当天**；落课与锁班都要往前留空档。

1. **比较合适：大约提前两个月安排（排进培训表 + 锁班／订教室尽量同步做）。**  
   例：11 月到期 → 优先排在 **9 月**；后面还有 10 月、11 月可以消化延误和改期。  
2. **最少也要提前约一个月。**  
   例：11 月到期 → 排在 **10 月** 也行，但余量更紧，延误一多就容易贴脸。  
3. **有窗口的项目**：提前量仍须落在规则窗口内；窗口怎么算见规则速查。不要为了「早点排」排到窗外（窗外会按死规则重开账）。  
4. **无窗口的项目**（安保、TSA、疲劳、作风等）：同样按「约提前两个月、至少约一个月」落课；不是拖到到期月才动手。  
5. **锁班／会议室**：表上有名字、日期不等于已经锁住；排定后按同一提前量去锁班、订教室（或确认教室），避免课表有、系统没锁、人飞不回来。

一句话：**目标提前约两个月；紧的时候至少提前约一个月；绝不贴到期日；排课与锁班尽量一起办。**

### 2. 盯表提醒（主人确认 · 每月常用七项）

**七项写清**：应急训练、危险品、航空安保、TSA、英语能力、汉语能力、CRM。  
对照年度培训表时按下面喊；输出用 **纯 txt**（不要 markdown）。不飞／特判仍听上文。

**报法铁律（防废话）**

1. **正常不展开**：已排、已覆盖、无漏 → 合并成一句短报，例：「11月：应急、危险品、航空安保、TSA、英语、CRM 已排已覆盖。」不要七项各写一遍「均已盖住」。  
2. **只报漏／异常**：哪项没排、谁没盖住到期、教员未定、该打签到表、该锁班／订教室、名单含领导——才单列。  
3. **不要报**：人次、场次日期清单（除非为指认「哪一天的教员／签到表／锁班」所必需）、重复的「正常／已盖住」句。  
4. **再下一个月**全空或很少 → 一句带过或不提；不展开。

**滚动提前量**

1. **最好提前一个月把「下一个月」七项排好。** 例：现在 10 月 → 盯 **11 月**；进入 11 月后再盯 12 月。  
2. 先点名盯哪个月；正常项一句打包「已排已覆盖」，空项／漏项单点名。  
3. 与上文「约提前两个月／至少一个月」一致。  
4. **负载均不均衡**：各月开班／人次是否扎堆；仅尖峰异常时喊一声。

**快到期（两步，报法同上）**

1. **排了没有** → **盖没盖住到期**（窗口细则见规则速查）。  
2. 全正常 → 并进「已排已覆盖」短句；有缺口 → 只写未盖住的人／项。

**分项（异常才喊）**

1. **危险品、航空安保、TSA**：漏排／未盖住才报。  
2. **英语、汉语**：考试项；漏排或未锁班才报；**不管教员**。  
3. **应急、CRM**：外地办班；开班前约 **提前一周** 提醒打 **签到表**（有才报）。  
4. **领导**：名单含领导才点单独通知／置顶。  
5. **不管**：考试结果；机器看／是否录入（月底月统一句即可）。

**已排场次（教员／锁班／会议室）**

1. **盯教员**：危险品、航空安保、TSA、CRM。按需要指认的日期问「×日××教员排了没」；**不报空白行数**。英语／汉语／无教员列的应急 → 不盯教员。  
2. **锁班／会议室**：危险品、安保、TSA、CRM 可合并提醒确认；英语／汉语侧重锁班。  
3. 应急／CRM 一周内开班 → 签到表。

**月底**

快到月底且需要时提一句月统收口。

## 三、排课两大原则

就这两条，别的都是细则或例外：

1. **不能过期**：该训的人到期前必须有能盖住本轮的安排；sheet 有名字但盖不住，仍算没排好。  
2. **均衡**：各月负载和到期压力尽量摊开，别堆成尖峰。TSA 历史扎堆往前分流是补救，不是「每年都应扎堆」。

提前量、领导多留裕度，都是在落实「不能过期」；安保 TSA 骨架摊匀，是在落实「均衡」。

## 四、实操怎么排（细则）

1. **有谁排谁**：认人表到期；该动的人进计划。不为曲线好看，给还早得很的人无故加整包。  
2. **sheet 有名字 ≠ 这轮完事**：日期盖不住本轮到期，还得改期或重排（盖不盖得住怎么判 → 规则速查）。  
3. **备注取消**：当没排。  
4. **安保 / TSA 双线**：分开看、分开记；TSA 一年一轮更密，先当骨架把月度摊匀；安保到期的插进去。不搞轻年重年，不劈安保半次。约 2026-11-02 起场次分场，台账仍两条。学时口算见确认稿。  
5. **TSA 扎堆分流**：前任长期未排造成的到期高峰，按必须动的人往前摊，是补救；稳态目标仍是各月养匀。  
6. **作风**：有安排就按期办班，不和个人窗口精细对齐硬抠。  
7. **疲劳**：表上空着就先别编排法。

## 五、CRM——未完成要统计（跟皇帝 CRM 口径）

CRM **不是有效期项目**，是**年度参加核对**。盯盘时除了报总未参加人数，还要拆开：**带队机长 / 非带队机长** 各多少未参加（以及应参加、已参加，便于对账）。

### 怎么数（与培训皇帝 CRM 年度核对一致）

1. **表**：只认精确名为 `CRM` 的工作表；`CRM2025(不参与统计)` 等含 CRM 但不叫精确名 `CRM` 的，不进当年核对。  
2. **年份**：默认统计当年；主人指定年份以指定为准。  
3. **已参加**：该年内，CRM 表有培训开始日期或结束日期落在该年，且备注不含「取消」。不看「培训信息是否录入」。  
4. **应参加**：人员信息表有员工号或姓名的人（含「是否运行 = 否」）。**CRM 教员**（3.1，跟皇帝）不进应参加 / 未参加。**评聘未上暂不排**（3.2）本年也不进未参加催促、不排学员课（评聘已算参加过）。  
5. **未参加** = 应参加 − 已参加。  
6. **带队机长 / 非带队机长**（不是体检里的「仅北美」）：看人表 `RAMA`、`REUO`、`RWAS`、`RSEA`——**任一有效**（非空，且不是 0 / 否 / 无 / 不适用 / false / no）→ **带队机长**；四项都无效 → **非带队机长**。  
7. **报数最低要求**：全年应参加、已参加、未参加；并按带队机长 / 非带队机长分别给出应参加、已参加、未参加。未参加名单需要时列姓名、员工号、分部、技术信息。  
8. **重复安排**：同一人该年多条有效 CRM 只作警告，不改变已参加 / 未参加判定。

口语里若说「北美带队」，CRM 这条**不要**改成只认 RAMA；CRM 跟皇帝，认四码带队机长。体检「北美带队」是另一套工具口径。

## 六、实操合不合逻辑（读法）

合逻辑的地方：

1. 有窗口的（应急、危险品、英语、汉语）提前量落在窗口能护锚点的区间里，没有普遍「提前半年重开账」。  
2. 按需开课；不飞与领导名册见飞行部人员天梯榜；安保教员 / CRM 特判见本页；排到领导：单独通知 + 多留裕度 + 更早排 + 名单置顶按层级序。  
3. TSA 先骨架再插安保，贴一年一轮更密的现实；扎堆当补救而不是当制度。

要盯的毛边：

1. 落课若缩到「到期当月才排」，和总口径（约提前两个月 / 至少约一个月）打架，延误一挤就贴脸。  
2. TSA 高峰分流是对的，但要标成补救，免得后人以为「五月就该堆」。  
3. 疲劳长期空表，人表仍有到期，别忘了另册盯，别默认「没排 = 没事」。
