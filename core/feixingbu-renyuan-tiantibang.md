## 定位

本页只管**人**：画像、座次、标签。两张梯子叠在一起看——

1. **组织层级天梯**：公司大领导 → … → 室主任（排课置顶、单独通知用这张）。
2. **技术档天梯**：副驾驶 A1→D、机长 B→F、当前教员 B/C（认档白话；统计人数听潜规则）。

特殊标签：**返聘（封号斗罗）**、**不飞**——可贴在任一层级／任一人上。

相关：
1. 排课怎么排领导／不飞 → 培训潜规则
2. 洗数、结构、周期、报务 → 南货航飞行部潜规则
3. 资格代码死表 → 资质代码／特殊机场资格代码
4. 公文版式 → 输出公文格式规约

---

## 天梯怎么读

1. **组织序**（1）→（6）从上到下；同档内按本页表内先后。培训表名单置顶、照顾面子用此序。
2. **级别写法**：斗罗档 + 职务（公司大领导／总经理／副总经理／分部经理／室主任）。斗罗档是内部顺口称呼，对外公文勿照抄黑话。
3. **技术档**与组织职级不是同一把尺：分部经理可以是机长或教员；返聘可以挂教员 B 或 F 类机长。认人时两把尺都看。
4. **特征备注**（改期、回消息、缺席催签名等）排课／通知时一并照看；本页维护备注，动手细则在培训潜规则。
5. 样表名单随实力表变；以当轮人员信息为准，本页滞后时点名待核，不臆造补人。

## 二、技术档天梯（认档白话）

认「他现在什么档」用这张；**出人数、周期、清洗分册**听 **南货航飞行部潜规则**。

### 副驾驶梯子（低 → 高）

**A1 → A2 → B → C → D**

1. 划转副驾驶归入 A1（结构口径）。
2. **E 类副驾驶不算副驾驶档**：是机长掉档，归机长侧（详见潜规则「实力结构」）。
3. 货航没有「副驾驶升机长」成长链；顶尖副驾常回流总队升机长。

### 机长梯子（结构常用）

**B → C → D → E → F**（及任务需要时的 Z 等）

1. E、F 含原 A 教迁入人员。
2. 谁在 CAPE／CAPF：以当轮技术等级导出或实力表为准，不在本页维护固定人名名单。

### 教员梯子（当前）

1. 当前教员仅 **B 教、C 教**，均为 **型别教员**。
2. 代码：技术等级 **CAPT**，水平 **B** = B 教，**C** = C 教。
3. 旧 **A 教（航线教员）** 已迁：CAPTA L1 → CAPE（E 类机长），CAPTA L2 → CAPF（F 类机长）；A 教资质统一截断于 **2026-08-31**，此后结构与报告不再单列 A 教。细则与统计见潜规则「技术等级与教员口径」。
4. 邢晓楠资质于 8.31 过期，不录入新资质（其人亦在不飞名单）。

### 与组织天梯的关系

组织职级管「通知／置顶／面子」；技术档管「能不能飞什么、统计进哪一档」。同一个人两张梯子都可能有位置。

## 三、特殊标签：返聘（封号斗罗）

### 在职状态通识

1. 货航存在退休返聘；系统状态栏部分人仍显示「退休」。
2. 不以状态栏「退休」单独判定已离开运行；以当轮名单、实力表或已确认范围为准。
3. 技术等级 **RCAP（返聘机长）** 可与状态「退休」并存；以资格段与名单为准。

### 返聘特殊人员（原级恢复，绝对不转机型）

原单位「777返聘」。局方领导、北方公司总经理、各层经理、现场管理部经理一类——**原来什么技术等级，回来就恢复什么等级**。

1. **绝对不做转机型**，也不从货航 A1 / 机长低档从头爬。  
2. 执照划转「转机型地点」空白很正常，**不要**当成交叉异常。  
3. 统计单独一档，不进晋升降本周期，不跟同机型划转大盘混均值（挖数时听潜规则，名单以本表为准）。
