# 外籍带飞批复合并

## 报装

合集「能做什么」时只取本段；改能力只改本文件。

```
外籍带飞批复合并
1. 场景：航季外籍带飞批复，确认航司 → 筛选开放部分 + 临开部分 → 合并总表 → 去程/回程录入表
2. 能干：纵向拼接不区分来源；多机场按机场列表展开；去程 A→B、回程 B→A；航路码全挂并蓝字；PORT/俄罗斯用模板 VLOOKUP
3. 口径：航司先确认，货航为CSG；生效失效主人指定；台湾飞行员整行照抄，空值作「否」；去程、回程各自非空才进对应表，不分析航路字符串
4. 节奏：先预检行数与空白，再按模板出结果；要与旧合并表比对时出根目录报告
5. 真源：仓内 templates/外籍带飞批复合并-模板.xlsx；辅助 scripts/waiji_daifei_merge.py
```

## 综述

启动说法包括「外籍带飞批复合并」「合并外籍带飞批复」「拆去程回程」。航司、开放表、临开表、生效/失效日期都已明确时直接执行；缺少航司范围时先问「本次录哪个航司？货航为 CSG，是否只处理 CSG？」。当轮已明确货航/CSG或其他航司范围时沿用，不重复询问，不把其他航司批复混入。

```
主人，皮燕子已武装。外籍带飞批复合并，已装备，弹药充足。

能干啥：先确认航司范围（货航为 CSG），从开放和临开两表筛出所选航司，不区分来源拼成一张 OD 总表后重编号；再按机场列表把伦敦/迪拜等多机场城市展开，拆出去程（航站A→B）和回程（航站B→A）。去程、回程各自只看源字段空白或非空白，有值才出对应方向；双向都空只保留合并原记录并提示。航路码整段保留，不拆逗号、不解释编号；有值方向展开后的每行全挂，多机场行蓝字；PORT 与是否俄罗斯走模板 VLOOKUP。生效/失效日期要主人指定；台湾飞行员照抄，空作「否」。

开火节奏：缺航司范围、开放表、临开表或生失效日期就只问缺项；能预检先预检。报告原始条数、按航司保留及排除条数，再核对方向空白与机场。结果与报告落仓库根目录（或主人指定路径）；仓内空模板本身不覆盖。
```

## 输入

1. 开放部分 xlsx（有表头：序号、公司、航站、航站、去程、回程、是否有台湾地区飞行员）。公司也可写「航空公司」，表头换行忽略；标题与执行日期/要求说明不是航线。
2. 临开部分 xlsx（可无独立表头行，数据列序与开放相同）。
3. 生效日期、失效日期（主人当轮指定；不臆造）。
4. 可选：旧版「开放与临开合并」表，用于比对。
5. 模板默认：`templates/外籍带飞批复合并-模板.xlsx`（含开放与临开合并 / 去程 / 回程 / 机场列表 / 俄罗斯机场列表；数据区为空，机场两表保留）。
6. 航司范围：处理前必须明确，可选一个或多个完整航司代码；数据室经主人确认货航为 CSG。未明确时先询问，不默认全航司。

## 业务规则

1. **筛选与合并。** 两表先按已确认的航司筛选，再开放在前、临开在后纵向拼接；不写来源标记；序号从 1 重编，不去重。公司代码去首尾空白、转大写后按完整代码匹配，CSGX不视为CSG，导出保留源公司写法。去程、回程均允许空，合并表保留所选范围内全部 OD；所选范围内公司与两航站必须完整，不默认为缺失公司补 CSG。公司空白或错误无法确定归属时阻止生成；已明确排除航司的行不参与航站、方向和机场检查。空选或所选航司无记录不得生成空结果。
2. **台湾飞行员。** 第 7 列整行照抄；读入时空白一律写成「否」。
3. **多机场展开。** 读模板「机场列表」A:B 中带尾数的中文名（伦敦1/2/3、迪拜1/2…），按去掉尾数后的基地名分组。OD 上若航站等于该基地名，则展开为全部编号变体；A、B 两侧各自展开后做笛卡尔积。上海/浦东等本身已是列表中的单名，不展开。
4. **去程表。** 列：序号、公司、航站A、航站B、PORTA、PORTB、去程、是否有台湾地区飞行员、生效日期、失效日期、起飞是否俄罗斯、落地是否俄罗斯。仅源去程非空才生成；源去程为空不出任何去程展开行。航站A/B 用展开后名称；去程航路码每行都写源去程字符串；因多机场展开而重复挂码的单元格用蓝色字体。PORTA/PORTB、是否俄罗斯写与模板相同的 VLOOKUP 公式。
5. **回程表。** 列名以模板为准（航站B、航站A 在前两航站列）。仅当源 OD 回程非空时生成；展开方式同去程，但左右航站对调；回程航路码全挂并蓝字。源回程为空 → 该 OD 不出现在回程表。
6. **方向语义。** 去程和回程独立判断：均非空出双向；仅去程非空只出去程；仅回程非空只出回程；均空不出方向表，保留合并原记录并提示。空白包括空单元格、空字符串及纯空白字符，不是必填错误。有值字段去首尾空白后整段照抄，不拆分逗号、不校验编号格式、不解释编号内容。源方向空白与有值方向的多机场重复行漏挂码不同，后者必须全挂并标蓝。
7. **日期。** 生失效由主人指定，写入去程/回程每一行；合并 OD 表不写日期列。

### 航站含义与墨西哥城机场

航站A、航站B表示航线两端的始发／目的地机场，不是同一机场的 T1、T2 航站楼。按主人确认的名称与代码，模板「机场列表」A:B 保留以下精确对应：

| 源航站名称 | 机场 | IATA代码 |
| --- | --- | --- |
| 墨西哥城空运机场 | 费利佩·安赫莱斯国际机场 | NLU |
| 墨西哥城国际 | 贝尼托·胡亚雷斯国际机场 | MEX |

这两个明确机场名各自只匹配一个机场，不按城市展开；原始名称不改写。仅源航站为基地名「墨西哥城」时，沿用模板「墨西哥城1／墨西哥城2」的多机场展开规则。普通合并执行时模板仍只读；其他未确认机场不据此猜码。

| **实写** | 以模板复制生成结果簿；写合并/去程/回程；可选比对旧表 | 不覆盖仓内空模板；不改主人源批复原件 |

## 辅助脚本

```
python scripts/waiji_daifei_merge.py run --open 〔开放xlsx〕 --temp 〔临开xlsx〕 --airline CSG --season 2026夏秋 --effective YYYY-MM-DD --expiry YYYY-MM-DD --reference 〔同航司范围旧合并xlsx〕 --report-txt 〔根目录报告txt〕
```

未传 `--output` 时按「最终文件名」写入仓库根目录。仅合并：`merge` 子命令。仅比对：`compare` 子命令。`--template` 默认真源模板路径。`merge` / `run` 必传 `--airline`，多航司重复传入，例如 `--airline CSG --airline CSN`；辅助函数默认 CSG，命令行不替主人确认范围。报告包含所选航司、各航司原始数量、保留和排除数量。

核心语义回归可运行 `python -B scripts/test_waiji_daifei_merge.py`，覆盖默认CSG与多航司范围、空选/无记录拒绝、范围内校验、公司表头别名、四种方向组合、航路文本原样保留与无空码方向表。

## 最终文件名

最终结果簿命名对齐「一二检和副驾驶进度更新」口径：主名 +「（由皮燕子…）」括号说明。

1. 默认格式：`{航季标签}外籍带飞开放临开合并（由皮燕子合并去程回程生效YYYY-MM-DD至YYYY-MM-DD）.xlsx`
   例：`2026夏秋外籍带飞开放临开合并（由皮燕子合并去程回程生效2026-03-29至2026-10-24）.xlsx`
2. 航季标签取主人当轮说法或源文件名中的航季（如 2026夏秋／2025冬春）；生失效用本轮写入去程/回程的日期；Windows 文件名不用斜杠，日期用连字符。
3. 主人指定输出路径时以主人路径为准，仍建议保留「（由皮燕子…）」段。
4. 比对报告、json 等过程件可另存根目录；最终给人用的交付件以带括号的 xlsx 为准。

## 铁律

0. **先确认航司与日期。** 未明确范围先问本次航司，未给生效/失效不得臆造写入；货航为CSG，当轮明确过就沿用，不能把其他航司批复录入货航。
1. **不改源件与空模板。** 开放/临开/仓内模板只读；结果另存。
2. **不区分开放/临开。** 合并后无来源列。
3. **两方向独立判断。** 只看各自字段空白/非空白；有值才出对应方向，不生成空码航段，不分析航路字符串。双向都空保留 OD 并提示。
4. **航路码全挂。** 多机场展开行不得只写首行；蓝字标记重复挂码。
5. **机场名以列表为准。** 列表没有的航站 VLOOKUP 会失败，预检时标出，不私自改码。
6. **结果落盘。** 最终 xlsx 按「最终文件名」；json／比对报告默认同目录；聊天只报路径与关键数字。

## 交付口径

主人，外籍带飞按〔航司范围〕筛选：原始开放×、临开×，保留开放×、临开×，排除其他航司×条。合并 OD × 行（去程源空跳过 ×、回程源空跳过 ×、双向源空 ×）；去程展开 × 行，回程展开 × 行；生失效 〔日期〕～〔日期〕。文件：〔带「由皮燕子」括号的完整路径〕。比对报告：〔路径〕（通过/未通过，含未知机场提示）。
