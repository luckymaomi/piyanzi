# 输出公文格式规约

## 报装

合集「能做什么」时只取本段；改能力只改本文件。

```
输出公文格式规约
1. 场景：写给人看的公文、工作报告、对比分析节选、按指定模板填稿
2. 能干：定三类稿件形态、用语禁区、先总后详、套仓内或主人指定模板
3. 铁律：报告禁止「现势」等内部黑话；形态听主人当轮需求，不擅自演成完整红头公文
4. 节奏：业务口径听各 Skill / 潜规则；本篇只管「写成哪种稿、版式跟谁」
```

## 综述

简短开场：“主人，技能已加载。出稿先认甲乙丙三类形态；用语与结构听本篇，数怎么算听对应业务 Skill。”  
出工作报告、报务／周期节选、或按指定模板填稿时加载或直办本篇。

口径蒸馏自集团工作报告格式样例，以及新员工公文培训材料中的通用规则；技能与模板均已去掉具体航司／单位名称，交稿时按主人当轮主体回填。

---

## 适用范围

1. 对外或可转发的 **公文稿 / 工作报告 / 分析报告（优先 docx）**。  
2. 聊天里可贴的结论段，尽量与公文同一套白话。  
3. **不算**：脚本变量名、Excel 内部表名、Skill 正文里的技术口径（那些可以保留「现势」「晋升降本」等内部词）。

业务统计怎么洗、怎么分册，仍以 **南货航飞行部潜规则** 及各业务 Skill 为准；本篇不另开统计产品。

---

## 用语禁区（报告正文）

1. **禁止写「现势」**。改成「当前」「目前」「截至某日」，或直接写对象（如「货航全部 C 类、D 类副驾驶」）。  
2. 禁止箭头符号当结论（如 FOA1→C）。  
3. 禁止光杆 `n=7`；写「共统计 X 人」。  
4. 禁止「窗口内 / 窗口外」；写清 **具体起止日期**。  
5. 等级对外用白话；代码可留附件或技能内部。  
6. 仓内模板与对外稿均勿回写未脱敏的航司全称／文头品牌，除非主人当轮明确要求按真名交稿。

## 文种与行文方向（通用）

常用文种骨架：决定、决议、通知、通告、通报、函、纪要、请示、报告、批复、意见。

1. **上行文**：下级对上级，如请示、报告；一般逐级行文，不越级。  
2. **平行文**：不相隶属单位之间，多用函。  
3. **下行文**：上级对下级，如通知、通报、批复、决定等。  
4. **通行**：纪要、意见等视场景。

选文种先看目的、再看行文关系：请求批准／指示 → 请示；部署工作 → 通知；向上汇报情况 → 报告；无隶属商洽 → 函。

通知／通告／通报勿混用：通知有明确对象与约束力；通告周知、可无特定主送；通报侧重典型或情况交流。  
非正式常用稿（讲话材料、情况说明、实施方案、签报等）不是本篇正式红头模板的替代文种。

**报告里不夹带请示**；有请示事项应改请示。标题用「关于……的报告／请示／通知／函」等规范结构，不生造文种，不语义重复（如「申请……的请示」宜去赘字）。

## 公文结构层次与数字

正文层次（与培训口径一致，字体以交稿环境为准）：

1. 一级：一、二、三……（黑体类，标题后一般不加标点）  
2. 二级：（一）（二）……（楷体类；标题后直接接正文时加句号，标题独占一行则不加）  
3. 三级：1. 2. 3.……（仿宋）  
4. 四级：(1) (2)……（仿宋）

数字：除结构层次序数及词语中的汉字数字外，一般用阿拉伯数字。成文日期用阿拉伯数字标全称年份，月日不编虚位（1 不写成 01）；成文日期取签发日。

标题回行避免以助词「的」起头。

---

## 附件、落款、印章、版记（要点）

1. 附件说明：正文下空一行、左空二字写「附件：」，多个附件用阿拉伯数字排序；附件名后不加标点、不加书名号；回行与附件名首字对齐。  
2. 印发类若正文后直接跟印发件，可不在正文再写附件标题。  
3. 请示、报告及需回复的函：附注留联系人与电话。  
4. 请示类上行文不加抄送。  
5. 会议通知、纪要、签报等按单位规定可不盖章；其余正式文种按规定用印。印章须与正文同页，禁止「此页无正文」凑章。  
6. 勿擅自改版记发文机关；抄送按序列归类排列。

---

## 结构：先总后详（分析／报告正文）

每一块两层：

1. **总述**：样本、口径、关键数字与判断。  
2. **详表**：明细；表题单独一行。

不要只写「见表2」；过程话（对齐字段、清洗公式、底表文件名）默认不进总述。清洗排除名单默认进 Excel 附件。

文字表达：准确、鲜明、简练、得体；先定行文意图与角色站位，再写层次。

---

## 表格

1. 表要少；能一张说清不拆多张。  
2. 列名短；完整日期写在总述。  
3. 报务检查完成量默认报 **人次**。  
4. 表题「表1  ……」居中。

---

## 三类稿件（先问清要哪一种）

默认先认主人当轮怎么交；没点名时，分析类任务按 **乙类节选** 出，不擅自加成完整公文。

### 甲类 · 正式工作报告（套红头）

完整公文壳：文头、主送、正文、专此报告、附件说明、落款、联系人、版记等按模板来。  
底稿：`templates/工作报告-集团公文格式模板.docx`（已脱敏）。  
用法：复制模板再填；按主体只留一套壳；占位换成主人指定真名与内容。分析数字进对应段落；详表可作附件，仍先总后详。

版式（改稿勿随意改）：A4；页边距上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm；标题方正小标宋简体 22 磅居中；正文方正仿宋_GBK 16 磅、首行缩进约 2 字、固定行距约 28 磅；页脚「－ 1 －」类页码。本机缺方正字体可能回落，交稿以单位环境为准。

### 乙类 · 分析对比节选（报务检查、运行周期等）

这是 **可嵌进更大材料里的片段**，不是演一场完整发文。

1. 只要：总述段落 + 必要详表（先总后详）；用语仍守本篇禁区。  
2. **不要**：红头文头表、文号签发人、主送、「关于……的报告」标题壳、专此报告、落款单位、成文日期行、联系人附注、抄送印发版记，以及装腔的开头收尾。  
3. 字体版式从简（仿宋约 16 磅即可），服务可读，不追求公文全要素。

### 丙类 · 按主人指定模板

主人丢了某个 docx／版式，或点名「跟某某模板一致」时：

1. **以该模板为唯一版式与结构来源**（页边距、字体、标题层级、有无文头落款，一律跟模板）。  
2. 只替换内容与数字，不改模板骨架；仓内工作报告模板若与指定模板冲突，听指定模板。  
3. 用语禁区、先总后详仍遵守；文种与附件细则能套则套，套不上的以模板原文位为准。

---

## 自检（交稿前）

1. 全文搜「现势」——对外稿应为 0。  
2. 当轮是甲／乙／丙哪一类？乙类是否误加了文头或落款？  
3. 有表时，表前是否有总述。  
4. 日期是否为具体区间。  
5. 甲类是否从脱敏模板复制填空；丙类是否与主人指定模板一致。  
6. 仓内 `templates/` 是否仍保持脱敏（未误存真名定稿）。
