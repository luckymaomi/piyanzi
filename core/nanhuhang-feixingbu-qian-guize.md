## 新窗口怎么干（数据分析主流程）

主人说「挖实力 / 出周期 / 对报告 / 洗副驾驶」时，按这个顺序：

1. **齐表**：问清本轮文件（见「当轮输入」）。通常要：飞行实力表、技术等级导出、运行资格导出；报无报务还要统计截止日。  
2. **定范围**：只副驾驶 / 只机长 / 两边都要？成长周期默认 **晋升降本** 与 **同机型划转** 分册，不混均值。  
3. **先清洗，再统计**：副驾驶技术等级清洗（只留777、同码首次生效、分册、交叉异常剔出大盘）→ 再出产品。  
4. **按「统计产品总览」勾要出的项**；主人没点名就先问要哪几类，或按报告常用套餐出（结构 + 运行→C/D + 报务两盘）。  
5. **对外数字**：与历史报告句对照时，骨架对上、量级大差不差即可（旧报告样本窗/版本不同，**不要死磕逐字相等**）。当轮须写清：样本册（全副驾 / 晋升降本）、起点规则（FOA1 首次 vs ≥2021-08-13 窗口）、截止日。  
6. **点名纪律**：异常、缺口、无报务名单一律 **姓名+工号**；不臆造归属。  
7. **交付**：按下方「交付规范」同步出 Excel + 说明文档；脚本落 `scripts/` 或根目录，主人确认任务结束前不清理。

口径变更只改本文件。调研来龙去脉见 `history/技术实力数据挖掘_调研过程记录.md`。

## 统计产品总览（要出什么）

下面每条都是「可以独立出的一盘数」。细则在后文同名主题块。

### A. 实力结构（现势有多少人）

| 产品 | 报什么 | 数据 |
| --- | --- | --- |
| 副驾驶结构 | A1/A2/B/C/D 各档人数、平均年龄；划转副驾驶归 A1；可报合计 | 实力表 · 人员信息 |
| 机长结构 | B/C/D/E/F 人数、平均年龄；不单列旧 A 教 | 同上 |
| 教员结构 | 仅 B 教、C 教人数、平均年龄等 | 同上 |

### B. 副驾驶成长周期（两套日期，勿混）

| 产品 | 口诀 | 报什么 |
| --- | --- | --- |
| 升级段周期 | A1→A2→B→C→D，默认 **检查日** | 每段：人数、最快、最慢、平均（可加中位数）；在途另报 |
| 运行 → 取得某档 | 进货航跑起来 → 第一次拿到某档，用 **生效日** | 例：运行→C、运行→D；起点=777 FOA1；仅晋升降本进成长均值 |
| 同机型划转册 | 单独一册，不跟晋升降本混平均 | 统什么当轮写清（划转日/恢复等级等）；清洗必分册 |

口诀：货航 **没有**「副驾驶升机长」成长链；C/D 顶尖副驾常回流总队升机长。

### C. 报务周期（副驾驶 · 两盘都要）

| 产品 | 口诀 | 报什么 |
| --- | --- | --- |
| 有报务盘 | 运行起点 → 第一条/北美/欧洲（可加西亚、东南亚） | 平均、中位数、有效样本；句式见「报务周期口径」 |
| 无报务盘 | 不上进：到截止日还没拿到 | 人数；已运行多久的平均/中位/最长/最短；名单 |

报务码（都算报务）：**EAMA、EEUO、EWAS、ESEA**。有任一=有报务；第一条=四码里运行后最早。

### D. 机长与监控（相对薄，按需）

| 产品 | 报什么 |
| --- | --- |
| 机长档位间隔 | 已是机长后的 B→C 等（生效日）；不做副驾→机长 |
| 一二检 | 左座进入→二检；最快/最慢/平均；在途 |
| 责任机长/区域单飞 | RWAS/REUO/RAMA 人数、缺口、培养；可与英语 E* 错配 |

### E. 清洗与分册（统计前必做，本身也是交付）

| 产品 | 报什么 |
| --- | --- |
| 副驾驶清洗结果 | 777 首次节点；与人员信息人头对齐 |
| 两册人数 | 晋升降本 / 同机型划转；返聘单独 |
| 阶梯完整性 | 晋升降本是否 FOA1…到当前最高档都有首次生效 |
| 交叉异常 | 原单位 vs 执照划转「转机型地点」；点名后不进整体统计 |
| 返聘（封号斗罗） | 原级恢复、不转机型；不进成长大盘 |

## 当轮输入：要齐哪些表

路径、版本以**主人当轮指定**为准；不默认沿用上一轮文件名。齐表前先问清：「具体是哪个文件、哪个 sheet」。

### 常用来源（叫法）

| 叫法 | 通常是什么 | 常用 sheet / 内容 |
| --- | --- | --- |
| 飞行实力表 / 人员实力表 | 南货航飞行实力表 xlsx | **人员信息**（名单、技术信息、原单位、分部等）；常还有 **执照划转**（转机型地点等）；进度类 sheet 按任务取 |
| 技术等级 | 技术等级导出（长表） | 员工号、代码、机型、生效日、失效日、水平等级等 |
| 运行资格 | 运行资格导出（长表） | 报务 E*、单飞 R*、机场等资格段与生效日 |
| 统计截止日 | 主人指定，或实力表/导出日 | 无报务「已运行多久」的终点 |

### 按任务要什么

| 本轮要干的事 | 至少要齐 | 还可能要 |
| --- | --- | --- |
| 只对口径 / 查名册 / 不通数 | 无表也可讲 | — |
| 实力结构（副驾/机长/教员人数年龄） | 实力表 · 人员信息 | — |
| 副驾驶技术等级清洗、晋升降本/同机型分册、阶梯核对 | 实力表 · 人员信息 + 技术等级 | 实力表 · 执照划转（交叉） |
| 机长侧清洗 / 划转交叉 | 同上 | 同上 |
| 副驾驶升级周期（A1→…→D，检查日） | 实力表名单 + 训练/检查日来源（主人点明哪张） | 技术等级（对照生效日，不与检查日混报） |
| 进入运行 → 取得技术等级（生效日） | 实力表 · 人员信息 + 技术等级 | — |
| 报务周期（有报务 + 无报务两盘） | 实力表 · 人员信息 + 技术等级（定运行起点）+ **运行资格**（EAMA/EEUO/EWAS/ESEA） | 统计截止日 |
| 一二检 / 机长进度 | 实力表（进度相关 sheet，主人点明） | 运行资格或技术等级按当轮 |
| 责任机长 / 区域单飞 | 实力表人员信息或运行资格（R*） | 英语 E* 对照时要运行资格 |

### 开跑前问法（缺什么问什么）

1. 本轮实力表是哪份？人员信息 / 执照划转用不用？  
2. 技术等级导出是哪份？  
3. 运行资格导出是哪份？（报务/单飞任务必问）  
4. 统计截止日用哪天？  
5. 本轮只做副驾驶、只做机长，还是两边都做？晋升降本 / 同机型划转是否分开报？

未点名的表：**不擅自用旧路径凑数**。

## 技术等级与教员口径（含 A 教迁移）

### 旧 A 教 → E/F 类机长

1. 旧称 **A 类教员 / A 教**：代码侧为 **CAPTA**，水平 **L1 / L2**。
2. 迁移：
   - CAPTA L1 → **CAPE**（E 类机长）
   - CAPTA L2 → **CAPF**（F 类机长）
3. A 教资质统一截断于 **2026-08-31**。此后结构与报告 **不再单列 A 教**，按 **E/F 类机长** 统计。
4. 邢晓楠资质于 8.31 过期，不录入新资质（其人亦在不飞名单）。

### 现势教员

1. 现势教员仅 **B 教、C 教**，均为 **型别教员**。
2. 代码：技术等级 **CAPT**，水平等级 **B** = B 教，**C** = C 教。
3. 航线教员（旧 A 教）口径已结束；勿再把 CAPE/CAPF 报成「A 教人数」。

1. 档：**A1、A2、B、C、D**（及任务需要时的其他副驾驶码）。
2. **划转副驾驶归入 A1**。
3. 各档报：**人数、平均年龄**；并可报副驾驶合计人数与平均年龄。

### 机长

1. 档：**B、C、D、E、F**（及任务需要时的 Z 等）；**不按 A 教单列**。
2. 各档报：**人数、平均年龄**；并可报机长合计人数与平均年龄。

### 教员

1. 只统计 **B 教、C 教（型别教员）**：CAPT 水平 B / C。
2. 可报各档人数、平均年龄，及是否责任机长等（字段在教员分级/实力表时取表内列）。

## 副驾驶升级周期（A1→A2→B→C→D）

### 统计什么

对每一跃迁段（A1→A2、A2→B、B→C、C→D）至少报：

1. **检查人数**（有效完成该跃迁的样本数）
2. **最快天数**
3. **最慢天数**
4. **平均天数**
5. 需要时加：**中位数**、去极值版均值/中位数

在途人员（尚未完成下一级）不进上述完成样本均值；另报在途名单与已耗天数。

### 日期间距

默认用 **检查日** 间隔（训练科目检查日：上一级检查 → 下一级检查）。与技术等级「生效日」差分开标注，不混报。

### 样本与窗口

1. 货航侧起算遵守「统计与数据挖掘起算」（默认 2021 年起 / 取证锚点）。
2. 机型锁 777。
3. 按年或按截止日切片时，在标题写清窗口。

## 副驾驶技术等级：怎么清洗（先洗数，再谈统计）

技术等级导出是长表：同一个人会有很多行（不同机型、不同等级、续期再录）。  
清洗目的：为每个副驾驶整理出「在货航 777 上、算成长用得着的首次节点」，并和实力表人员对得上。

名单以实力表「人员信息」为准。副驾驶人数应与人员信息里技术信息含「副驾驶」的人数一致（样表约 200 人）。其中技术信息写成「划转副驾驶」、或 E 类副驾驶等、还对不上 A1～D 码的，单独点名挂起，不假装已经进阶梯。

### 只留 777

货航现在就跑 777。  
技术等级行里机型不是 777 的（73X、329、190 等），**不算货航运行/成长节点**。  
人还在，只是这些旧机型履历不拿来当「在货航开始跑」的日子。

### 一模一样的行去重

同一人、同一代码（如 FOA1）、同一机型 777、生效日和失效日都一样 → 留一行就够。

### 同一个人、同一个码有多段时，取「第一次拿到」

系统常会给同一个人、同一个资格码写好几段（续期、再录入）。  
问「他第一次拿到这个资格是哪天」时：**只认生效日最早的那一段**。  
后面同码的新段还在履历里，但不当成又一次「第一次」。

举例：蓝锦坚（273295），777 上 FOA1 有两段：

1. 2023-02-13～2023-08-05  
2. 2024-11-04～2025-03-12  

算「第一次当上 A1 / 开始按 A1 跑」→ 用 **2023-02-13**。  
第二段是后来又录的，不是他又重新「第一次」当 A1。

机器做法：按「员工号 + 代码 + 机型777」分组，组内按生效日排序，取最早一条为该码的首次节点。

清洗键：`员工号 + 代码 + 机型`。非唯一形态与收口原则见 `history/技术实力数据挖掘_调研过程记录.md`。

### 按原单位分成两册人（再用划转表交叉，不能全信）

看实力表「原单位」主判：

| 册 | 原单位 | 白话 |
| --- | --- | --- |
| 同机型划转 | 总队777、上海、新疆 | 同机型过来，原来什么技术等级，到货航可以按原等级接上，不必再从货航 A1 重新爬到 D |
| 晋升降本 | 河南、广西、湖北等其余 | 要在货航 777 上从运行成长走过等级 |

举例：

1. 彭田（271938），原单位广西分公司 → **晋升降本**。他有 777 的 FOA1（2023-08-22），后来升到 D，这是正常成长样本。  
2. 黄俊豪（263416），原单位总队777 → **同机型划转**。他的等级链条按划转册看，不跟彭田那种人混在同一个「货航从 A1 爬到 D」的篮子里。

样表量级（随表变）：副驾驶约 200 = 同机型划转约 127 + 晋升降本约 73。

**交叉核对（机长、副驾驶同理）**：实力表「执照划转」sheet 的 **H 列「转机型地点」**。  
地点是**空白**的，多半表示同机型划转（没去别的地方转机型）。可拿来和「原单位=总队777/上海/新疆」对一下。

但划转表**更新不及时，不能当唯一真理**。

**先把返聘剔出交叉异常**：原单位含返聘的，按「返聘特殊人员」办，地点空白不算异常。

其余对不上的人：

1. **点出姓名工号**，写进异常清单（过程可查）。  
2. **不进当轮整体统计**（均值、结构大盘、周期样本）——异常是小头，宁缺毋滥，不要硬塞进大头口径。  
3. 不擅自改成晋升降本或同机型划转；名单留给主人另判。

异常类型举例（返聘除外）：

1. 原单位像同机型，但转机型地点写了翔翼/新加坡等。  
2. 转机型地点空白，但原单位不是总队777/上海/新疆（如重庆航空、顺丰、总队919等）。  
3. 原单位像同机型，划转表根本没有这个人。

交叉对不上只点名、不进大盘；过程表落当轮根目录交付即可。

### 晋升降本要留住整条梯子

晋升降本副驾驶，清洗后在 777 上应能看到：从 FOA1 一直到他**现在最高档**，中间每一级的「首次生效」都在。

1. 现在是 C 类 → 应有 FOA1、FOA2、FOB、FOC。  
2. 现在是 D 类 → 再加 FOD。  
3. 缺一环 → 写出姓名工号当异常，不能闷声当没这回事。

举例：彭田现在是 D，清洗后应能看到 FOA1、FOA2、FOB、FOC、FOD 各自的首次生效日；FOA1=2023-08-22，FOD=2026-09-27。

「第一次拿到」以技术等级**生效日**为准（系统录入生效），不是训练检查日。

### 同机型划转怎么处理

1. 这些人单独一册。  
2. 不要求他们「必须有一段 2021 年之后的 FOA1 才算数」——很多人划转前在总队 777 早就有 A1～D。  
3. 也不要把他们的历史 FOA1→D 天数，和晋升降本的人混成一个平均周期。  
4. 划转册具体统什么（划转日、恢复等级等）→ 统计口径另写；本块只定：**清洗时分册、不混篮**。

### 洗完自检（人话）

1. 副驾驶人头能否对上人员信息（差的人要能报出名字）。  
2. 晋升降本：每人有没有 FOA1；最高档之前每一级有没有首次生效。  
3. 两册人数相加是否等于副驾驶总数（挂起未入档的要单列说明）。

辅助脚本（可选）：`scripts/check_fo_ladder_completeness.py`、`scripts/run_fo_clean_pipeline.py`。

## 机长侧路径与清洗（货航没有「副驾升机长」这条链）

### 业务白话

货航 777 是重型机，**在货航这条线上，基本不搞「副驾驶一路升成机长」**。

常见样子是：

1. **机长**：从外面（多为总队777等同机型）**已经是机长**划转进来；进来就是机长档（含后来当教员的）。  
2. **副驾驶**：引进/划转到货航当副驾，在货航往上走到较顶尖的副驾（常见到 **C / D**），再 **回流总队** 去升机长——升机长主要发生在总队，不在货航统计「副驾→机长」成长链。

所以：统计货航成长时，**不要**做「货航副驾驶升机长」的周期均值；机长人数结构、机长划转另册看。

### 机长怎么分册（与副驾驶同理）

1. 名单以人员信息为准；技术信息是机长 / 教员的，进机长侧（教员可再拆，见「技术等级与教员口径」）。  
2. **同机型划转机长**：原单位总队777/上海/新疆为主判；再用执照划转「转机型地点空白」交叉，对不上就点名异常（见副驾驶清洗「两册+交叉」）。  
3. **返聘机长 / 返聘教员**：原级恢复、不转机型；单独一档，不进交叉异常、不进成长周期大盘（名单见「返聘特殊人员」）。  
4. **其他来源机长**（分子公司转机型、外籍、顺丰等）：不跟「总队777同机型直接恢复」混篮；交叉对不上 → 点名并从整体统计剔除。  
5. 机长技术等级清洗仍锁 **777**、同码取首次生效；结构档 B/C/D/E/F（及 Z 等）按当轮表。  
6. 货航侧可盯：机长结构人数、划转入职、责任机长/区域资格等；**不盯**「本单位副驾首次升上机长」作为主成长指标。

### 和副驾驶册的关系（一句话）

副驾驶晋升降本：在货航爬 A1→…→C/D。  
副驾驶同机型划转：进来接等级，常到 C/D 后回流总队。  
机长：划转进来已是机长（或教员），不算货航副驾晋升终点。

## 进入货航运行 → 取得技术等级（生效日，晋升降本）

清洗按「副驾驶技术等级清洗」做完之后，才谈周期。仅 **晋升降本**（同机型划转不进本产品均值）。

常用产品名：

1. **运行 → C 类副驾驶**：起点 FOA1 → 终点 FOC 首次生效。  
2. **运行 → D 类副驾驶**：起点 FOA1 → 终点 FOD 首次生效。  
3. 其他档同理（→A2 / →B …）。

规则：

1. **运行起点**：777 上 FOA1 首次生效日（与报务等产品共用；若主人要求「仅 ≥2021-08-13 窗口内的 FOA1 段」当轮写清）。  
2. **取得某档**：该档代码首次生效日（不是检查日）。  
3. 周期 = 终点 − 起点（天）。有 C/D 却追不到 A1 → 点名异常。  
4. 输出：平均、中位数、有效样本；在途（有起点尚未拿到该档）可另报已耗天数。

## 报务周期口径（副驾驶 · 进入货航运行 → 报务）

洗完副驾驶技术等级、定好「进入货航运行」起点之后，才做本块。默认对象：**副驾驶**（晋升降本为主；同机型划转是否同口径，当轮写清）。  
开跑前按「当轮输入」齐：**实力表人员信息 + 技术等级 + 运行资格 + 统计截止日**；缺哪份问主人要具体路径。

码对照（报务 E*，不是单飞 R*）。  
下面这些**都算报务**，有任一即算「有报务」；「第一条报务」= 运行后这些码里生效日最早的那一条：

| 口语 | 代码 |
| --- | --- |
| 北美报务 / 美加报务 | EAMA |
| 欧洲报务 | EEUO |
| 西亚报务 | EWAS |
| 东南亚报务 | ESEA |

分区统计时仍可单独报 EAMA / EEUO / EWAS / ESEA 各自周期；「有没有报务 / 无报务」用上面四码并集判断。
### 定义

1. **起点**：进入货航运行。晋升降本 = 777 上 FOA1 首次生效日；同机型划转起点是否改用划转日，当轮写清。  
2. **终点**：对应报务的首次生效日（运行之后、该码最早一段）。  
3. **周期** = 终点 − 起点（天）。

### 清洗

1. 报务生效日**早于**运行起点：单独标记；周期改用「运行后最早报务日 − 起点」。  
2. 机型锁 777；人从实力表副驾驶名单来，与清洗后人头对齐。  
3. 人分成两盘，**两盘都要出数**，不要只报有报务的那盘。

### 有报务（已拿到终点）

进「获得报务」的均值 / 中位数 / 有效样本。  
无运行后报务、或根本无报务记录的人 **不进** 这一盘的平均数和中位数。

默认至少出：第一条报务（四码并集最早）、北美（EAMA）、欧洲（EEUO）。需要时再加西亚（EWAS）、东南亚（ESEA）或极值版。每类报：平均周期、中位数、有效样本。

### 无报务（不上进 · 运行了多久还没拿到）

运行起点之后，到统计截止日仍 **没有** 对应报务（或没有任何报务）的人——口语里就是「不上进」那拨。  
**必须单独统计**，不能因为没进均值就当不存在。

1. **已运行天数** = 统计截止日 − 进入货航运行起点（天）。截止日当轮写清（导出日 / 实力表日 / 主人指定日）。  
2. 至少报：无报务人数；已运行天数的 **平均 / 中位数 / 最长 / 最短**；名单（姓名+工号+起点日+已运行天数）。  
3. 可按缺口拆：四码全无（真·无报务）、有报务但无北美、无欧洲、无西亚、无东南亚等——当轮需要哪档拆哪档。  
4. 这一盘是「拖了多久还没拿到」，**不要**和「拿到报务的周期均值」混成一个数。

### 对外句式（照填数字）

有报务盘：  
从进入货航运行到获得第一条报务的平均周期为 X 天，中位数为 Y 天，有效样本 N 人；获得北美报务的平均周期为 X 天，中位数为 Y 天，有效样本 N 人；获得欧洲报务的平均周期为 X 天，中位数为 Y 天，有效样本 N 人。报务早于货航运行时间的人员已单独标记，并选取运行后的最早报务日期计算周期；无运行后报务或无报务记录的数据未纳入本段平均数和中位数统计。

无报务盘（接上或另段）：  
截至统计日，仍无第一条报务 M 人，进入货航运行以来平均已运行 A 天，中位数 B 天，最长 C 天，最短 D 天（名单另附）。无北美 / 无欧洲同理，需要时各报一截。

历史报告量级（旧样本，仅作「别太离谱」参照，不必逐字追平）：第一条约 538.56 / 488 / n99；北美约 681.70 / 681.5 / n64；欧洲约 582.35 / 509 / n85。  
当前表重跑会因人数、划转占比、FOA1 窗口不同而浮动；出数时写清样本与起点规则即可。

相关动手：副驾驶积分「报务资质清洗」见 **副驾驶流转更新**（晚于 A1 取最早段）；本块是**报告口径与句式**，积分表是**填表清洗**。

## 一二检与责任机长（监控要点）

### 一二检周期

1. 货航：左座进入时间 → 二检（完成日）；报检查人数、最快/最慢/平均天数。
2. 在途：已耗天数、距任务线（如二检≤270 天）是否超期。
3. 总队对照若做：起算规则另定（如 Z 类机长起算），不与货航混用同一起点名。

### 机长相关（货航不做副驾升机长链）

1. 已是机长之后的档位变化（如 B→C）可用生效日间隔；是否含教员段当轮写清。  
2. 实力表「机长进度」：进入机长时间、左座阶段经历/起落等，作在途监控。  
3. 不要把「货航副驾驶首次升上机长」当成默认成长口径。

### 责任机长与区域单飞码

实力表 / 运行资格中常用区域单飞标记（有码=具备）：

| 代码 | 口径称呼 |
| --- | --- |
| RWAS | 西亚 |
| REUO | 欧区（除俄） |
| RAMA | 北美 |

培养/增聘监控：各区域责任机长人数、缺口、培养周期（首聘及分区）；与机队需求对照时需求侧数字由当轮任务给出。

英语侧常对照：EAMA（北美）、EEUO（欧区除俄）、EWAS（西亚等）——与单飞码配对看出错配。
