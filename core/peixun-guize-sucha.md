## 这页要干什么（业务，不是程序）

本 Skill 对齐培训皇帝「飞行部培训规则速查」那一页的业务灵魂：

1. **读懂规则配置在说什么**——每个项目：别名、规则类型、有效期长短、窗口、到期取整。  
2. **用固定案例看结果**——旧有效期 + 培训开始日期 → 命中窗口与否 → 新有效期。  
3. **填表别踩坑**——人表有效期为准、取消/机器看/录入字段各干什么、安保与 TSA 分记。

不讲：培训皇帝怎么改代码、怎么扫 sheet、怎么画压力图。那些是工具维护，不是本 Skill。

口径来源：培训皇帝规则配置 / `training-rule-spec`；规则变更时以培训皇帝为准，再回写本文件。

## 三类规则白话（先懂这个）

### 1. 基准月（目前：应急训练）

首次培训定下「基准月」。以后复训若落在基准月前后约 1 个月窗口内 → **基准月不变**，有效期按旧锚点顺延一轮；窗口外 → **按本次培训月份重建基准月**，再算新有效期。到期取整到**月底**。

### 2. 三个月窗口（危险品；英语/汉语能力）

从失效日前 3 个日历月起算窗口。  
- **危险品**：必须在失效**前一日**及之前完成（失效日当天不算命中窗口）；命中则沿用旧到期日顺延 2 年。  
- **英语 / 汉语**：窗口含失效日当天；命中则沿用旧到期锚点顺延（英语 3 年、汉语 6 年）。  
未命中窗口（提前太多或超期）→ 按**本次培训开始日期**重算，不再护旧锚点。取整：**当日**（不落到月底）。

### 3. 最新日期（航空安保、TSA、疲劳管理、飞行作风）

**没有窗口、没有保护锚点。** 只认最新一次培训开始日期，直接加有效期重算。安保 24 日历月、TSA 12 日历月、疲劳/作风 24 日历月；取整**月底**。安保与 TSA 是两个独立项目，各记各的 sheet。

## Excel 填写规范（业务口径）

规则计算仍以培训皇帝核心配置为准；下表是填表时别搞反。

| 场景 | 填写方式 |
| --- | --- |
| 人员信息表有效期 | 每个有效期项目维护一列，到期日以人员信息表为准。 |
| 项目 sheet 有效期列 | 用于人工查看；排班判断和有效期更新以人员信息表有效期列和项目培训日期为准。 |
| 培训信息是否录入 | 不作为有效期更新开关；已录入且有效期已被当前有效期吸收的记录作为历史参考，其余安排按日期规则判断覆盖。 |
| 机器看 | 写「Y」时参与有效期更新；备注包含「取消」时按异常跳过。 |
| 备注取消 | 备注包含「取消」时，这条排班记录按取消处理。 |
| 航空安保 | 做了航空安保，就在「航空安保」sheet 记录。 |
| TSA | 做了 TSA，就在「TSA」sheet 记录。 |
| 同一天做航空安保和 TSA | 「航空安保」sheet 记一条，「TSA」sheet 也记一条。 |

2. 导入整本培训总表做排班总览 / 漏项 / 负载 / CRM 年度核对。
