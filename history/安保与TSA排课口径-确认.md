# 安保与 TSA 排课口径（确认稿）

记录约：2026-10-22  
用途：对齐学时、台账、预算与排课方案；给后续排课和工具口径对照。  
正式文件若冲突，以公司/局方正式文件为准。

---

## 一、学时与台账（已对齐）

| 项目 | 学时 |
| --- | --- |
| 航空安保初训 | 6 学时（含考核） |
| 航空安保复训 | 6 学时（内容、时间与初训一致） |
| TSA | 4 学时（含考核） |

**两科都要上时的加减（公共课口径）：**

- 内容上：安保 6 + TSA 4  
- 其中约 **2 学时是公共课**，不重复计  
- **合计按 8 学时计**（此算法已确认成立）  

说明：减 2 认的是**课程内容重叠（公共课）**，不是「必须同一安排才减」。  
因此：**同年（或同一轮）两线都到期、两科都要完成时——哪怕场次已经分开——预算/学时合计仍是 4+6−2=8**，不是 10。  
只上 TSA、不上安保时，计 **4**；只上安保、不上 TSA 时，计 **6**（无公共课可减给另一科时，按单科计）。

**课时与钟点（当前）：**

- 现行常见：1 学时 = 45 分钟 → 8 学时上课钟点约合 6 小时  
- **台账仍按科目课时记（安保 6、TSA 4），不能把合计 8 改记成实际钟点 6**  
- **做预算：单科按 4 或 6；两科都上按合计 8**  

**已透露的后续可能：**

- 以后可能改为 **1 课时 = 1 小时**，大纲或将随之修订  
- 修订落地前，仍按上表执行  

**台账铁律（已对齐）：**

- 安保与 TSA **分开展示、分开记台账**（两条线）  
- 场次可分可合，台账始终按 **安保 6 + TSA 4** 分落，不合成一笔糊账  
- 口语「8」= 两科都上时的**学时/预算合计**，不是把两条有效期合成一条

## 二、目前怎么排（现行做法）

1. 用培训皇帝导出 **TSA 必须排**、**安保必须排**。  
2. **先排 TSA**：一年一轮更密；提前约一年排布时，把 TSA **排均衡**。  
3. **再插安保**：名单里安保也到期的，把安保安插进计划。  
4. **场次形态（分场节点前）**：同一安排里常一起上；学时两科都上则按合计 8。  
5. **约 2026-11-02 起**：同一安排里 **不再合训**，场次必须分开；台账本来就要分开；两科都上时学时仍按 **4+6−2=8**。  

一句话：**双线名单；TSA 为骨架排匀；安保按必须排插入；台账永远分开；两科都上合计 8。**

不引入「轻年 / 重年」概念——谁该上哪科，只看两条截止日与必须排名单。

## 三、方案全览

讨论过的集合如下。 **主推且足够用的是方案 D（双线 + 分场）**；不必再叠轻年/重年。

| 代号 | 名称 | 可用性 |
| --- | --- | --- |
| A | 年年两科都打满（合计年年 8） | 不可用 |
| B | 轻年 / 重年（4+8 节奏标签） | 讨论过，**不采用**（多余） |
| C | 安保内容拆 A/B 半次 | 不推荐 |
| D | 双线整次 + 分场执行 | **主推 / 最佳** |

**所有方案共性必盯（资格底线，谁都不能省）：**

1. **TSA 有效期截止日**（及最晚完成日 / 必须排·推荐排）  
2. **航空安保有效期截止日**（同上）  
3. 已排培训日期能否**覆盖**本轮到期（含已排未覆盖）  
4. 备注取消、应录入未录入、两科完成是否写入**对应 sheet**  

---

### 方案 A：年年两科都打满（合计年年 ≈8）

**做法**  
每人每年都把安保+TSA 上满一轮，两年 ≈ 8+8。

**优点**  
- 排课决策粗暴简单。  

**缺点**  
- **预算不可接受**。  
- 安保过密。  
- 容易误以为「年年都上过就不用看截止日」——截止日仍必须盯。  

**资质监控要盯的参数**  
- **必盯：** TSA / 安保 有效期截止日；必须排；覆盖；分 sheet；取消/未录入  
- **加盯：** 两年总课时是否按「人人年年 8」爆表  

**结论**  
已排除。

---

### 方案 B：轻年 / 重年（4 + 8）——不采用

**做法（仅作历史讨论记录）**  
按个人安保周期人为标轻年（只 TSA 4）/ 重年（两科合计 8）。

**优点**  
- 曾用于解释「为什么不是 8+8」。  

**缺点**  
- 多一套「轻/重」概念，增加沟通与出错面。  
- 真正决定上不上的仍是两条截止日；轻/重是多余标签。  
- 与主推的双线分场重复，无额外资质管理收益。  

**结论**  
**不采用。** 预算用「只上 TSA 计 4；两科都上计 8；只上安保计 6」自然结果即可，不必命名轻年重年。

---

### 方案 C：安保内容拆 A / B 半次——不推荐

**做法**  
安保拆 A/B，两年各上半，TSA 年年跟。

**缺点**  
半次续期无口径、监控状态爆炸。  

**必盯**仍含两条截止日；另多 A/B 完成态等地狱参数。  

**结论**  
不推进。

---

### 方案 D：双线整次 + 分场执行——最佳 / 主推

**做法**  
- 有效期两条；**整次完成才续对应那条**。  
- **场次分开**：TSA 独立场；安保独立场。  
- 名单：皇帝拉 TSA 必须排、安保必须排；先排匀 TSA，再把安保必须排合并进来（须单开就单开）。  
- 台账：永远 6 与 4 分记。  
- **学时：** 只 TSA → 4；只安保 → 6；**同一轮两科都要上 → 4+6−2=8**（公共课减 2，与是否同一安排无关）。  

**优点**  
- 最贴「台账分开、场次分开」。  
- 监控干净：主盯两条截止日 + 必须排，无半次、无轻/重年。  
- 与培训皇帝分类一一对应。  
- 分场政策下可直接落地。  
- 两科都上时学时仍是 8，**不存在「分场就变成 10、高于合训」的问题**。  

**缺点（真实剩下的）**  
- 场次数量变多（两场召集），行政成本高于「同一安排合训」。  
- 分部会延误会影响 TSA 场，要有补训出口。  
- 合并安保必须排的步骤不能省（见第四节漏洞）。  

**资质监控要盯的参数**  
- **必盯：** TSA 有效期截止日；航空安保有效期截止日  
- **必盯：** TSA / 安保 必须排·推荐排·已过期；已排覆盖 / 已排未覆盖  
- **必盯：** 两科 sheet 分记；取消 / 未录入  
- **加盯：** 场次科目标明 TSA 或安保，防串记  

**结论**  
**这就是最好的方案。** 不必叠轻年/重年。

## 四、现行操作法详解（= 方案 D 的名单手法）

日常真实做法就是方案 D 的排课手法；分场节点前只是场次曾可合在同一安排，**逻辑已是双线**。

### 4.1 核心思想

1. **主监控轴 = TSA 截止日 → 必须排 → 排均衡**  
2. **辅合并轴 = 安保截止日 → 必须排 → 合并进计划（分场后另开场）**  
3. **刷新皇帝** 后名单重算；不靠心算  

不标轻年/重年：某人这轮只上 TSA 还是两科都上，**只看两张必须排名单有没有他**。

### 4.2 具体怎么操作

1. 更新总表，打开培训皇帝。  
2. 导出 **TSA 必须排**、**航空安保必须排**。  
3. 先铺 TSA，排匀。  
4. 再合并安保必须排：已在 TSA 计划里的 → 分场后另开安保场；不在的 → 单独开安保场。  
5. 上台账：分 sheet；两科都完成则预算/学时合计按 8。  
6. 下轮排课前再刷新。  

### 4.3 日常要盯的参数

| 优先级 | 参数 | 干什么用 |
| --- | --- | --- |
| 主 | TSA 有效期截止日 / 最晚完成日 | 主轴 |
| 主 | TSA 必须排（及是否用推荐排） | 主名单 |
| 主 | 各月 TSA 已排人数 | 均衡 |
| 并 | 安保有效期截止日 / 最晚完成日 | 谁该合并 |
| 并 | 安保必须排 | 合并清单；漏则漏人 |
| 核 | 已排未覆盖 | 改期/重排 |
| 核 | 取消、是否录入 | 覆盖与历史 |
| 台 | 两科分 sheet | 防假续 |
| 预 | 本轮计 4 或 8（两科都上）或仅 6 | 自然结果，不搞轻/重年标签 |

### 4.4 漏洞

| 漏洞 | 怎么堵 |
| --- | --- |
| 没刷新 / 旧必须排名单 | 排课前重导重算 |
| 只导 TSA、忘并安保必须排 | 写死第二张表；合并勾选 |
| 安保必须排不在 TSA 班又忘单开 | 分栏：搭车另场 / 须单开 |
| 只写一个 sheet | 两科都完成必须两科都有记录 |
| 已排未覆盖 | 排后回看皇帝 |
| 总表录错 | 健康检查 + 抽查 |
| 忽略清单未维护 | 与人员信息同步 |

「自动」= 刷新工作台后按最新表重算必须排；「不漏」= 每轮都刷新并合并安保表。

### 4.5 约 11-02 分场后

- 名单步骤不变。  
- 只改：不再同一安排；TSA 一场、安保一场。  
- 两科都上时学时仍 **8（4+6−2）**。

## 六、TSA 到期不均衡的原因（历史事实）

表上 TSA 有效期截止日**明显不均衡**（例如大量集中在 2027-05 前后），**不是**规则本身要求「五月扎堆」，也**不是**现行排课故意造成的最优形态。

**根因（已确认写入）：**  
上一任培训管理员疏忽，**长期没有按周期安排 TSA 培训**。资质却仍须维护，有效期在人表上照常滚动/堆积，于是到期日被挤到同一时段。  

**后果：**  
现任只能在接手后做**补救式均衡**——用培训皇帝按必须排往前分流（例如按月约 30 人摊到 2027-05 前），属于**不得不维护资质**的被动安排，不是正常稳态排班。  

**稳态目标：**  
分场 + 双线整次（方案 D）跑顺之后，应按 TSA 一年一轮把各月到期**养匀**；历史高峰消化完，不应再依赖「大挪移」当常态。

## 七、预算最少时怎么排（总而言之）

1. **每科都上完整的**：安保一次满 6、TSA 一次满 4；**一定不要把安保内容劈开（禁止 A/B 半次）**。  
2. **按需开课**：以截止日 + 皇帝必须排为准；有谁排谁，不为「看起来均衡」给未到期的人无故加整包（TSA 历史扎堆提前分流除外，那是补救）。  
3. **场次可分、内容不劈**：分场后一场只上一科；台账分记；同一轮两科都要上 → 学时合计仍 4+6−2=8。  

这就是方案 D 的预算口径：**完整课 × 按需**，不是轻/重年，也不是年年 8+8。

---

## 八、一句话对照

- **最佳方案：** 双线分开（场次分、台账分）；按截止日与必须排做事；**整次、按需、不劈课**。  
- **学时：** 只 TSA=4；只安保=6；两科都上=4+6−2=**8**（公共课，与是否同场无关）。  
- **不用：** 年年 8+8；安保 A/B；轻年/重年。  
- **必盯：** TSA、安保两条有效期截止日（任何方案都不省）。  
- **最大洞：** 忘刷新或忘并安保必须排。  
- **TSA 不均衡：** 前任未排课遗留；现排是补救维系资质，不是规则要求扎堆。
