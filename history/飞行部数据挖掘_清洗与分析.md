## 最终确认方案

一句话：先把人洗对、分册对，再按产品出口径；交付用 Excel + 说明；入口加载「南货航飞行部潜规则」。

### 数据用什么

1. 实力表 · 人员信息：现势一人一行  
2. 技术等级、运行资格导出：算周期、核对履历  
3. 执照划转（转机型地点）：同机型线索，表可能不及时  
4. 现势锁 777；成长统计常看 ≥2021、锚点 2021-08-13 一带（当轮写清）

### 清洗怎么做（已确认）

1. 副驾驶只留 777；同码取首次生效。  
2. 按原单位分成册：**晋升降本** / **同机型划转**（总队777、上海、新疆）；返聘单独，原级恢复不转机型。  
3. 键：`员工号 + 代码 + 机型`；续期链取最早一段；不要用日历窗口砍掉链条起点 A1。  
4. 归属不清的交叉异常点名，不进整体统计。  
5. 晋升降本清洗后，阶梯应完整（FOA1…到当前最高档）；有完整历史阶梯的同机型人 ≠ 应进晋升降本周期。

### 分析出什么（已确认）

1. 结构人数、升级段周期、运行→某档（如 C/D，晋升降本、生效日）。  
2. 报务：EAMA / EEUO / EWAS / ESEA 都算；有报务 / 无报务两盘都出。  
3. 货航没有「副驾驶升机长」成长链；机长多是划转入。  
4. 对外数字白话写清（平均多少天、中位数多少天、共统计多少人）；窗口不对齐不硬比。  
5. 交付：清洗明细 + 统计表 + 说明文档；脚本落盘。  
6. **E 类副驾驶**：机长因能力不合格掉档；报务检查等人群统计 **按机长计**，不进副驾 A1～D。
