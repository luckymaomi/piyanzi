## 一、一句话

南货航飞行部训练管理室的**资质管理（地面）**，本质是：在 **777 单一机型、2021 年取证后独立运行** 的约束下，把「人能不能飞、能不能进什么档、资格录没录对、培训有没有过期、实力长什么样、对外怎么说清楚」这条链持续跑通——**系统不可全信，表要洗，名单要认，预检与实写要分开，对外稿要白话**。

岗位不是单纯「录资质码的人」，而是同时扛：

1. **认人与例外**（谁是领导、谁不飞、谁返聘）  
2. **资格与录入**（代码字典、录入通知预提示、机型只认 777）  
3. **培训组织**（有效期算法、排课潜规则、完成粗统计）  
4. **副驾驶成长台账**（积分流转门槛 + 实力表经历进度）  
5. **技术实力清洗与分析**（结构、周期、报务两盘）  
6. **规章与迎审**（手册／大纲原文核对、检查单符合性）  
7. **航季批复**（外籍带飞，货航代码 CSG）  
8. **对外交付**（Excel＋说明／公文三类形态）

皮燕子仓把上述拆成可加载弹药；**Skill 是工作记忆，不是替代主人拍板与录入系统**。

清单分组即办事地图：

```

  └ 分身（岗位对齐，不复制细则）

人员画像
  └ 飞行部人员天梯榜（人：组织序 + 技术档 + 返聘／不飞）

通识与挖数
  └ 南货航飞行部潜规则（数：齐表→清洗→结构／周期／报务）

交付出稿
  └ 输出公文格式规约（怎么写成稿；数怎么算听业务篇）

培训
  ├ 飞行部培训规则速查（有效期／窗口死规则）
  ├ 培训潜规则（排课动手、特判、提前量）
  └ 培训完成粗统计（年度表粗点人头期数）

资质
  ├ 资质代码（死表）
  ├ 特殊机场资格代码（死表）
  └ 资质录入检查预提示（拆通知→预检清单）

副驾驶与进度
  ├ 副驾驶流转更新（积分总表公式与可流转门槛）
  └ 一二检和副驾驶进度更新（实力表经历回填；人机分界）

迎审
  └ 检查单手册比对填写（原文符合性 + 佐证 PDF）

规章阅读
  ├ 飞行技术管理手册阅读（管理链：取得／保持／恢复／权限）
  └ 飞行人员训练大纲阅读（课程／课时／失败处理）

航季批复
  └ 外籍带飞批复合并（开放+临开→去回程录入表）
```

读图口诀：

1. 问「谁／什么标签」→ 天梯榜  
2. 问「怎么算人数与周期」→ 潜规则  
3. 问「怎么排课」→ 培训潜规则（算法回规则速查）  
4. 问「录什么码」→ 录入预提示 + 两本代码表  
5. 问「积分能不能流转」→ 流转更新（清洗仍听潜规则）  
6. 问「手册允不允许」→ 规章阅读；「检查单怎么填」→ 迎审  
7. 问「怎么写成报告」→ 公文规约

## 四、两张梯子：组织与技术

资质岗天天同时用两把尺，**不能混成一把**。

### 4.1 组织层级天梯（老大 → 小弟）

公司大领导 → 安监部 → 飞行部班子 → 分部经理 → 安全／技术室主任 → 以下按实力表认人。

用途主要在**培训与通知**：单独通知、名单置顶、多留改期裕度、按层级序排面子。职级与能不能飞无关，但排课漏了领导成本极高。

### 4.2 技术档天梯

| 侧 | 梯子 | 要点 |
| --- | --- | --- |
| 副驾驶 | A1 → A2 → B → C → D | 划转副驾结构上归 A1；**E 类副驾驶不算副驾档**（机长掉档，归机长侧） |
| 机长 | B → C → D → E → F（及 Z 等） | E／F 含原 A 教迁入 |
| 教员 | 当前仅 B 教、C 教（型别） | 旧 A 教（CAPTA）迁 CAPE／CAPF，截断 2026-08-31，报告不再单列 A 教 |

货航业务硬事实：**没有「副驾驶在货航升机长」的成长链**。副驾常爬到 C／D 后回流总队升机长；机长多为同机型划转进来已是机长。

### 4.3 特殊标签

1. **返聘（封号斗罗）**：原级恢复、绝对不转机型；状态栏「退休」不能单独判离开；统计单独一档，不进晋升降本／同机型大盘均值。  
2. **不飞**：培训侧所有训不监控、不硬排；挖数是否剔除当轮写清。  

标签可贴在任一层级／任一人上（返聘且不飞很常见）。

## 五、数据底座：先洗对，再谈数

### 5.1 常用输入三件套

| 叫法 | 用途 |
| --- | --- |
| 飞行实力表 · 人员信息 | 名单、技术信息、原单位、分部；结构人数主表 |
| 技术等级导出 | 长表；等级首次生效、清洗节点 |
| 运行资格导出 | 报务 E*、单飞 R*、机场资格等 |

报无报务还要**统计截止日**。路径以主人当轮指定为准，不擅自用旧文件凑数。

### 5.2 清洗铁律（副驾驶技术等级）

1. **只留 777** 节点算货航运行／成长。  
2. 同人同码多段 → 取**首次生效**（最早生效日）。  
3. **两册分清、不混均值**：  
   - 同机型划转：原单位总队777／上海／新疆为主判  
   - 晋升降本：河南、广西、湖北等其余  
4. 执照划转「转机型地点」可交叉，但**更新不及时，不能当唯一真理**；对不上点名挂起，不进大盘。  
5. 返聘先剔出交叉异常（地点空白正常）。  
6. 晋升降本应能看到从 FOA1 到当前最高档的整条梯子；缺环点名。

### 5.3 统计产品（潜规则总览）

1. **实力结构**：副驾各档／机长各档／B·C 教人数与平均年龄  
2. **成长周期**：升级段多用**检查日**；「进入运行→取得某档」用**生效日**；两套勿混；成长均值默认只进晋升降本  
3. **报务周期两盘都要**：有报务（运行→EAMA／EEUO 等）＋无报务（到截止日还没拿到、已运行多久）  
4. **报务检查**口语＝训练科目「英语通信单飞航线检查」；年度检查完成量 ≠ 运行→拿码周期  
5. **机长与监控**：一二检、责任机长／区域单飞（RWAS／REUO／RAMA）等，相对薄、按需  

交付默认：**Excel（清洗明细＋统计）＋说明文档**；对外结论白话句式，禁止箭头与 `n=`。

### 5.4 时间与范围纪律

1. 货航侧统计默认 **≥2021**，锚点 **2021-08-13**。  
2. 多航司／多单位表先确认「这次只处理谁」；程序能跑 ≠ 全部可录货航。  
3. 预检报原始量／范围内量／排除量；异常是核查线索，不猜归属、不补值。

## 六、资质代码与录入：预检优先

### 6.1 两本死表

1. **资质代码**：资格码 ↔ 中文名、类型、岗位机型要求、有效期等——只查不编。  
2. **特殊机场资格代码**：机场与排班／资格码对照。

### 6.2 录入预提示的工作方式

主人甩通知／名单 → 拆成「每人录什么、不录什么、先核什么」→ 映射报务／单飞／机场 → 套录入铁律 → 出清单；**默认不代点飞行门户／天健**。

高频心智模型：

1. **报务 E\*** ≠ **单飞 R\***（美报 EAMA ≠ 北美单飞 RAMA）。  
2. 机型组／机型资格默认只有 **777**。  
3. 例外句（「不添加机型」「仅恢复××」）必须写进人名下。  
4. A1 同步机型、型别教员 CAPTB 同步 SIMT、退回副驾取消 ACAP、重航划转路径等——见录入铁律，以通知例外为准。

录入岗的价值不在「手快」，在**少录错、少漏同步、疑点提前摊开**。

## 七、培训：算法 → 排课 → 出数

三条 Skill 是一条链，不要拧成一团。

| 环节 | Skill | 管什么 |
| --- | --- | --- |
| 算法 | 飞行部培训规则速查 | 八项训的有效期／窗口／续期（基准月、三月窗口、最新日期三类） |
| 动手 | 培训潜规则 | 不过期＋均衡；不飞／领导／安保教员／CRM 特判；提前量；安保·TSA；CRM 未参加分带队／非带队 |
| 出数 | 培训完成粗统计 | 年度培训表有效记录粗点人头／期数；≠通过人数 |

八项常见项目：应急、危险品、航空安保、TSA、疲劳管理、飞行作风、英语能力、汉语能力。  
安保与 TSA **分项目、分有效期**（安保约 24 日历月、TSA 约 12 日历月，最新日期类、无窗口）。

排课两大原则（培训潜规则）：**不能过期**优先，再谈**负载均衡**。领导四条：单独通知、多留裕度、更早排、名单按天梯序置顶。

粗统计铁律：表内有效记录就算；不看是否参加／机器看／是否通过；日期用培训结束日期；出稿前加总核对。

历史画像（`history/培训工作画像_从接手到工具.md`）说明真实路径：先被有效期与系统 bug 打脸，再沉淀规则，再用「培训皇帝」等工作台输出给人核对——**人做最终确认**。资质岗培训线同样是这个哲学。

## 八、副驾驶两条台账：积分 vs 进度

常被混谈，Skill 边界很清楚。

### 8.1 副驾驶流转更新（积分总表）

追踪 777 副驾从进货航到**可流转**的积分与门槛。清洗听潜规则；公式与进不进总表听本篇。

可流转须同时满足（摘要）：总分 ≥1000、已有 C 类、已有欧洲报务＋美加报务、本机型飞行月数自 A1 起 >48、C 类运行月数 >3。排名只对已有 C 的人做。

本表专规排除（注意与潜规则分册不同）：E 类副驾驶、原单位含新疆、个别点名人员等——**潜规则新疆可进同机型划转册，积分总表仍排除**。

### 8.2 一二检和副驾驶进度更新（实力表）

从实力表抽名单与起算日 → 填 CSN2API 查询模板 → **主人自行跑网页** → 回填左座／阶段经历与起落。  
不登录、不代跑接口。一二检默认只更上方首块；**不套用积分表排除名单**。

两条台账共用「实力／等级／资格」数据源，但**目的、名单规则、写入目标都不同**。

## 九、规章、迎审与航季

### 9.1 规章阅读

1. **技术管理手册**：谁在什么条件下取得／保持／失去／恢复什么资格；岗位、座位、航线、机场权限；审批与生效。  
2. **训练大纲**：课程、课时、失败处理、保持与恢复等训练细节。  

边界：依据本轮真实批准文件；教程不代替原文；阅读结论**不自动改资质、不代发审批**。时间词（日历日／日历月／基准月／窗口）严禁互换硬套。

### 9.2 迎审检查单

符合性声明必须**手册原文一字不差**；语义比对后复核；对不上留空，不编不润色。需要佐证则按条款抽 PDF 并高亮条款号。

### 9.3 外籍带飞批复

开放＋临开合并 → 按机场列表展开去程／回程录入表。先认航司（货航 CSG）；空白方向不生成航段；行数多、方向空、机场未匹配是核查线索，不猜值。

## 十、对外怎么说：数与稿分离

1. **数怎么算**：潜规则／培训粗统计／各业务篇。  
2. **稿怎么写**：输出公文格式规约——甲红头工作报告、乙分析节选（无文头落款）、丙指定模板。  
3. 用语：当前／目前／截至某日；禁止内部黑话简称当前实力结构；禁止箭头结论与光杆 `n=`；先总后详，有表先有总述。  

挖数交付默认 Excel＋说明；进度更新例外：校验成功后只留主人命名的实力表，清理本轮过程件（底表永不擅自删）。

## 十一、工作方法论（贯穿全部 Skill）

从 AGENTS 与各篇「作战阶段」抽出的共同纪律：

1. **没有调研，就没有发言权**——先摸表结构、范围、窗口、叫法，再开口径。  
2. **预检 ≠ 实写**——预检可对账、拟稿、出清单；实写先备份，备份失败则停。  
3. **缺项只问缺的**——已明确范围沿用；不扩大任务。  
4. **不臆造**——表外无码不编；异常点名；空方向不补航段。  
5. **脚本与结果落盘**——先写再跑；任务结束前不擅自清理过程文件。  
6. **人机分界**——代跑生产网页／代录系统／代发审批，默认不做，除非主人明确授权。  

这不是「工具文化」，是资质岗在监管与运行双重压力下的**防翻车文化**。

## 十二、一张业务闭环（理想一周／一轮汇报）

用故事串起来（示意，非固定日程）：

1. **认人**：天梯榜核对领导／不飞／返聘是否变动。  
2. **盯训**：规则速查算到期 → 潜规则排课与特判 → 粗统计给报告句子。  
3. **录资质**：通知来了走录入预提示；疑点带代码表问清再录。  
4. **养副驾**：刷积分总表门槛与预警；按需更新实力表一二检／副驾进度。  
5. **看实力**：齐三表 → 清洗分册 → 结构／周期／报务 → Excel＋说明；对外套公文规约。  
6. **遇迎审／问条款**：手册大纲原文；检查单照录。  
7. **航季**：CSG 批复合并展开，核验后交录入。  

每一环失败模式不同：排课怕过期与领导改期；录入怕 E／R 混挂与漏同步；挖数怕混册与混日期；迎审怕概括手册；批复怕认错航司。

## 十三、我对这份工作的判断（综合）

1. **资质管理在货航，是「地面上的运行安全接口」**——把局方／手册要求翻译成可执行的名单、码、表、课和报告。  
2. **难不在单一规则，而在叠层**：组织面子 × 技术档 × 培训窗口 × 系统脏数据 × 对外话术，任一层偷懒都会在另一层爆雷。  
3. **777 单机型看似简单，实际把「历史机型履历」变成永久噪音**——所以清洗与锁机型是第一生产力。  
4. **晋升降本 vs 同机型划转**是理解货航副驾队伍的钥匙：存量 CD 往往划转带来的多，本单位从 A1 养出来的周期是另一盘账；混报会骗管理层。  
5. **报务是国际运行的硬门槛**，所以周期要「有／无」两盘；积分流转还把欧美报务写进可流转条件——培训、资质、积分在此汇合。  
6. **Skill 化是把个人记忆变成可交接资产**：长假失忆、同事代班、复盘口径，都靠篇而非靠脑子。  
7. **边界清晰本身就是产能**：天梯榜不管洗数、潜规则不管排课、公文不管统计、进度不管积分排除——减少「一个聊天框里五套口径互殴」。
